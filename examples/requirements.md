# Reference examples

Examples validate the [core guarantees](../kit/docs/architecture/rules.md), not a preferred framework or directory tree.

The reference scenario is [void an invoice](void-invoice.md). Its business policy is a fixture specification, not a universal billing requirement.

Executable examples must identify their pinned/supported toolchain, exact setup and verification commands, and infrastructure. Do not create a runnable application merely to satisfy directory symmetry; add only code needed to exercise the relevant guarantees.
